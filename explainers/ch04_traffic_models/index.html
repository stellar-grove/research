Three traffic laws, one data set

Several speed-density laws look plausible. Can the data tell them apart, and does the choice matter?

Chapter 4 · Validation: accept, improve, or reject. A worked example rebuilt from the chapter's topic in Mike Mesterton-Gibbons, *A Concrete Approach to Mathematical Modelling*; the scenario and numbers are our own illustration, not the book's text. The detector data on this page are simulated from Greenberg's law with known parameters, so the methods can be checked against the truth (see the table at the end).

Headline: All three laws track the data closely (R² 0.91–0.99), yet AIC picks Greenberg decisively (weight 1.00), and residual patterns rule out the straight line. The choice matters: predicted lane capacity ranges from 1,442 to 1,693 vehicles an hour.

The problem

A loop detector records 120 one-minute readings of traffic density (vehicles per mile) and mean speed. Three classic laws describe how speed falls as density rises. Which one does the evidence support, and would picking the wrong one change the engineering answer (the lane's capacity)?

The candidates

Greenshields: v=vf(1−kkj)Greenberg: v=clnkjkUnderwood: v=vfe−k/km

Each has two parameters, so AIC differences come purely from fit. Each also implies a capacity qmax=maxkkv(k) (Greenshields vfkj/4, Greenberg ckj/e, Underwood vfkm/e).

Key findings

  • Fit statistics alone can mislead. All three have R² above 0.91; the straight line's residuals, though, run in long same-sign stretches (runs test p = 0.000), the signature of a missing curve.
  • AIC finds the true law here: Greenberg gets weight 1.00, and its parameters land near the planted values (c = 17.3, k_j = 227, true 17.2 and 228).
  • Tests err at their stated rate. The runs test flags even the true law here (p = 0.048): at the 5% level it does so in about 1 data set in 20, which is why the truth table below records a fail rather than quietly dropping the check. Judge a model on several diagnostics, not one p-value.
  • The decision depends on the choice. Capacity estimates span 1,442–1,693 veh/h (truth 1,443) because the laws differ most where data are thin: validate in the regime you will use the model for.

import numpy as np
from books.concrete_mathematics import equilibrium as eq, validation as va
rng = np.random.default_rng(42)
k = np.sort(rng.uniform(15, 190, 120))
v = eq.greenberg_speed(k, 17.2, 228) + rng.normal(0, 1.2, k.size)
fit = va.fit(lambda k, c, kj: c * np.log(kj / k), k, v, p0=[15, 250], names=["c", "k_j"])
print(np.round(fit.params, 2), np.round(fit.ci(), 1).tolist())

Assumptions and extensions

  • Simulated data make the truth knowable; real detector data add measurement error in density and a scatter of driver types.
  • Equal parameter counts make AIC a pure fit comparison; with unequal counts its penalty matters (Chapter 8's likelihood-ratio test is the nested-model alternative).
  • Real flow-density data often show a capacity drop (a two-regime curve) that none of these smooth laws capture: reject all three if your use case lives there.
